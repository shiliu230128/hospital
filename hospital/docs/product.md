# 产品说明

## 项目定位

医院挂号入口比选助手是一个面向患者和家属的静态网页工具，用来整理重点城市三甲/三级医院的可信挂号入口，并支持按城市、区域、科室、距离和入口类型做初步比较。

默认城市是北京。用户切换到上海、深圳、杭州后，页面会刷新为对应城市的医院、区县、街道/乡镇参考点、医院坐标、微信入口和排班状态；当前四城都已接入部分公开排班样本，但覆盖不均匀。

它解决的是“去哪里找官方入口、哪些医院值得先看、不同入口怎么比较”的问题，不解决自动预约和抢号问题。

## 目标用户

- 需要在北京、上海、深圳、杭州多家医院之间选择挂号入口的患者或家属。
- 给老人、儿童、异地亲友代查挂号信息的人。
- 不熟悉某个城市医院体系，希望先快速筛出候选医院的人。
- 需要确认医院官网、权威公开页、公众号、小程序、114 或本地预约平台入口是否可信的人。

## 典型使用场景

1. 用户知道医院名，想快速找到官网、权威公开页或微信入口。
2. 用户知道科室方向，想看当前城市哪些重点医院可以先尝试。
3. 用户有位置约束，想按某个街道/乡镇附近距离排序。
4. 用户切换城市后，希望区县、街道、医院和坐标数据同步刷新。
5. 用户想把多个医院加入对比区，再逐个打开官方入口确认。
6. 用户想看公开出诊样本，但知道最终是否可约必须以官方入口为准。

## 当前功能

- 默认北京，支持切换上海、深圳、杭州。
- 各城市目标医院 registry，并用 seed 覆盖审计暴露缺口。
- 医院官网或权威公开挂号/机构入口。
- 已核验微信公众号、服务号、小程序入口；未核验二维码不展示二维码。
- 微信二维码点击放大。
- 区县、科室、关键词、日期偏好筛选。
- 手动选择街道/乡镇作为位置参考，并按近似距离排序。
- 四个城市少量公开出诊样本展示。
- 候选医院对比区。
- 数据来源和自动刷新时间展示。

## 明确不做

- 不自动预约。
- 不自动抢号。
- 不高频刷号。
- 不保存身份证、医保号、手机号、病历、挂号账号密码。
- 不绕过验证码、登录、防护页面或平台限制。
- 没有 L3/L4 授权数据前，不展示“当前可挂”“剩余号源排序”。

## 数据能力分级

- L0：医院基础信息和官方/权威公开入口。当前可稳定展示。
- L1：公开出诊安排，例如医生、日期、上午/下午、停诊提示。当前只代表公开排班。
- L2：日期或科室级是否可能有号，只能作为弱提示。
- L3：医生、日期、时段级当前可挂状态。可支持“只看可挂”。
- L4：剩余号源数量或订单级可挂校验。可支持余号排序和提醒。

当前原型以 L0/L1 为主。北京、上海、深圳、杭州均有少量 L1 公开排班样本，但主要覆盖少数官网公开表和公开接口。实时余号必须等授权接口或稳定合规数据源。

## 交互结构

页面采用工作台形态，而不是营销首页：

- 顶部：城市、区县、位置参考、搜索、日期、时段、排序。
- 左侧：常见科室和数据能力提示。
- 中间：医院结果和筛选状态。
- 右侧：医院官网或权威公开入口、微信入口、公开排班样本。
- 对比区：保留候选医院和入口。

用户可以从城市、医院、科室、区域、位置任一入口开始，不需要按固定问卷一步步填写。
